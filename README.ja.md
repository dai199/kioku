# Kioku

**macOSで選んだテキストをその場で翻訳します。履歴は学習素材として貯まり、週に一度、覚える価値のある表現をAIが選び出します。**

[English README](README.md)

<!-- スクリーンショット: ポップアップ翻訳（選択 → アイコン → 訳文） -->

Kioku は、英語を学ぶ日本語話者のためのメニューバー常駐アプリです。どのアプリでも
テキストを選ぶだけで翻訳でき、調べた内容が学習素材として貯まります。週に一度、
AIが履歴を読んで「覚える価値のある表現」だけをカードとして提案し、間隔反復で定着させます。

汎用の翻訳アプリではありません。**実際に出会った英語を翻訳し、そのうち意味のあるものを
覚える**という一本のループのために作られています。

## できること

- **どこでも翻訳** — どのアプリでもテキストを選ぶと小さなアイコンが出て、
  クリックで訳が表示されます。ブラウザ、Slack、PDF、エディタなど
- **本文置換** — 英語を書くとき、日本語を選べば採用した英文に置き換わります。
  ブラウザにコピーして貼り直す往復が要りません
- **方向を指定して作り直す** — もっとカジュアルに / もっとフォーマルに / もっと短く
- **詳しく** — その訳の文法とニュアンスをAIが解説します
- **週次レポート** — 1週間分の翻訳をAIが読み、繰り返しつまずいているパターンを指摘し、
  カード候補を提案します。承認したものだけが復習に入ります
- **間隔反復（SRS）** — 3段階の自己評価で復習。1日20枚を上限にして、
  1回のセッションが5分以内に収まるようにしています
- **2つのエンジン** — Gemini（クラウド・自然な訳・トーン指定可）と
  Apple翻訳（端末内・オフライン・無料・外部送信なし）

## プライバシー

**テキストがいつ端末を出るのかが分かる**ように作っています。

- **クリックするまで何も送りません。** 選択した時点ではアイコンが出るだけで、
  通信は一切発生しません
- **一切送らないエンジンを選べます。** Apple翻訳なら端末内で完結します。
  オフラインで動き、費用もかからず、テキストがMacから出ません
- **Geminiの場合もあなたの鍵とアカウントです。** Kioku にサーバーはありません。
  テキストはあなたのMacから、あなたが設定したプロバイダへ直接送られます
- **除外アプリ。** パスワードマネージャーは既定で除外済みで、任意のアプリを追加できます。
  除外アプリではアイコン自体が出ません
- **データはローカルに残ります。** 履歴・カード・レポートは、
  アプリケーションサポート配下のSQLiteに保存されます

なお無料枠のAPIキーを使う場合、送信した内容がプロバイダの製品改善に利用される可能性が
あります。各プロバイダの規約をご確認いただくか、気になる場合はApple翻訳をお使いください。

## 動作環境

- macOS 26.0 以降（Apple翻訳を使う場合は 26.4 以降）
- アクセシビリティ権限（選択したテキストの読み取りに必要）
- Gemini を使う場合はAPIキー（[取得はこちら](https://aistudio.google.com/apikey)）

システムワイドに選択テキストを読むにはAccessibility APIが必須で、これはApp Storeの
サンドボックスと両立しません。そのためMac App Storeでは配布できません。

## インストール

ビルド済みバイナリはまだ配布していません。現状はソースからビルドしてください。

## ソースからビルドする

Xcode と [XcodeGen](https://github.com/yonaskolb/XcodeGen)（`brew install xcodegen`）が必要です。

```sh
git clone https://github.com/dai199/kioku.git
cd kioku
make run     # プロジェクト生成 → ビルド → 起動
```

**署名チームの変更が必要です。** `project.yml` の `DEVELOPMENT_TEAM: C8FHUZ27C7` は
作者のApple Developer Team IDです。ご自身のものに置き換えるか、空にしてXcodeで選択してください。

`Kioku.xcodeproj` は `project.yml` から生成される成果物でgit管理外です。
ターゲット・ビルド設定・依存の変更は必ず `project.yml` を編集してください。

```sh
make build   # xcodegen generate → xcodebuild build
make test    # ユニットテスト
make run     # ビルドして起動（起動中のKiokuは落とす）
make clean   # .build と生成物を捨てる
```
