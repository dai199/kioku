macOSで選んだテキストをその場で翻訳します。履歴は学習素材として貯まり、 週に一度、覚える価値のある表現をAIが選び出します。 英語を日常的に読み書きする人のための、メニューバー常駐アプリです。

The loop

選ぶselect

どのアプリでもテキストを選ぶと、小さなアイコンが出ます。 クリックするまで何も送信されません。選んだだけでは通信は起きません。

置き換えるreplace

英語を書くときは、日本語の下書きを選ぶだけ。採用した英文が 書いていたその場所で入れ替わります。もっとカジュアルに、 もっとフォーマルに、もっと短く——納得するまで方向を指定できます。

貯まるaccumulate

翻訳はすべて手元に残ります。どのアプリで、いつ調べたかも一緒に。 多くのツールが捨てている部分ですが、価値があるのはここです。

選ばれるcurate

週に一度、AIが履歴を読んで、繰り返しつまずいているパターンを指摘し、 カード候補をいくつか提案します。承認したものだけが復習に入ります。 勝手にカードは増えません。

覚えるremember

間隔反復で復習します。3段階の自己評価、1日20枚まで。 1回のセッションが5分を超えないようにしてあります。

これがこのアプリの考え方そのものです。ページの冒頭で一度見た文を、 少し経ってから思い出そうとしていただきました。Kiokuは同じことを、 あなたが実際に出会った英語で、分単位ではなく週単位の間隔で行います。

プライバシー

  • クリックするまで何も送りません。 選択した時点ではアイコンが出るだけで、通信は発生しません。
  • そもそも一切送らない選択肢があります。 Apple のオンデバイス翻訳を選べば、テキストはMacから出ません。オフラインで動き、費用もかかりません。
  • Kiokuのサーバーは存在しません。 APIキーはあなたのものです。テキストはあなたのMacから、あなたが設定したプロバイダへ直接送られます。
  • 初めから除外されているアプリがあります。 パスワードマネージャーは既定で除外済みで、任意のアプリを追加できます。除外したアプリではアイコン自体が出ません。
  • 履歴は手元に残ります。 翻訳・カード・レポートは、自分で中身を確認したり削除したりできるローカルのデータベースに保存されます。

導入

まだ公証を通していないため、ビルド済みの配布物はありません。ソースからビルドしてください。 読めるコードを自分で動かす形なので、Gatekeeperの警告を回避する必要もありません。 macOS 26 と Xcode が必要です。 

brew install xcodegen
git clone https://github.com/dai199/kioku.git
cd kioku
make run

選択したテキストを読むためにアクセシビリティ権限が必要です。同じ理由で Mac App Store では配布できません。詳しい手順は README にあります。
